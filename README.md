# Bank Management System

## Overview
The Bank Management System is a Python-based application connected with MySQL that helps manage basic banking operations. It provides a simple menu-driven interface to perform account-related tasks efficiently.

## Technologies Used
- Python
- MySQL
- PyMySQL

## Key Features
- Create a New Bank Account
- View All Account Details
- Deposit Money
- Withdraw Money
- Check Account Balance
- Delete an Account

## Database Setup
Import the `Database.sql` file into MySQL before running the application.

## Installation
1. Install Python and PyMySQL.
2. Create the MySQL database using the `Database.sql` file.
3. Update the MySQL connection details (host, username, password, and database name) in the Python file.
4. Run the Python program to start the application.
